## Описание задачи

<!-- Кратко опишите задачу: что предсказываем, какой датасет, метрика качества -->

**Задача:** [Классификация]

**Датасет:** [Brazillian E-Commerce]
Датасет был выбран потому что:
1. Он содержит все сушности необходимые для предсказания прибыльности (цена, доставка, вес товаров, геолокацию), кроме себестоимости, её подбор и будет одной из основных задач.
2. Содержит реальные данные в большом количестве (100+ тысяч заказов)
3. Публичный и подходил под описание (тип monetary)

**Целевая метрика:** [ROC-AUC / F1 / Precision]
1. ROC-AUC работает в дисбалансе классов, оценивает качество ранжирования
2. F1-score важна, когда критично не пропускать убыточные заказы
3. Precisiom показывает, какая доля прогнозируемых прибыльных действительно прибыльна
